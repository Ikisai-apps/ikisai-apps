# Fragmentos del CHANGELOG del kit

Cada PR del kit deja aquí su nota (`<número>-<tema>.md`) y **no toca** `package.json`, `package-lock.json` ni `CHANGELOG.md`.
Así las PR abiertas no chocan entre sí cada vez que entra una (acordado con Core Ops el 27-10).

Al cerrar una tanda, UI-kit abre una PR de versión: sube `version`, pasa los fragmentos a `CHANGELOG.md` (los más nuevos arriba) y los borra.
